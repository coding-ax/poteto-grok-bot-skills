# poteto-grok-bot-skills

摸鱼Agent研究所自用的 Grok Bot 技能库。

起因是看了 [@poteto](https://x.com/poteto)（Lauren）写的那篇 Grok Bot 养成指南，觉得说得太对了，就照着把自己团队收拾了一遍：裁了两个 Bot，停了一个最费用量的定时任务，然后把常干的活写成技能放这里。

## 她那篇指南，我的理解

- Bot 不用多，几个好用的比一大堆好管
- 你教 Bot 怎么干活的时候，让它顺手写成技能，以后每次都按同一套来，聊久了也不跑偏
- 连接器、密码库、工具都给它配上，它还能有自己的邮箱，自己注册账号
- 想想哪些活你还在手动复制粘贴给 Bot，直接问它能不能自己搞
- 把它当新来的实习生：先介绍你自己和你的工作，再问它能帮你自动化什么
- 语音把想法一股脑倒给它，最后让它"用你自己的话复述一遍"，确认没理解错
- 定时任务别太勤，最多一小时一次；订阅类的先过滤再触发
- 能写成脚本的就别让 Bot 硬干，脚本几乎不花 token
- 像经理一样想：怎么让 Bot 干得跟你一样好，甚至更好

原文去 [@poteto](https://x.com/poteto) 主页看，比我总结的好。

## 怎么用

两种办法，选一个：

1. 把 `skills/` 下面某个文件夹整个拷进你 Bot 的技能目录
2. 直接跟你的 Bot 说："读一下这个仓库里的 `skills/xxx/SKILL.md`，存成你自己的技能"

建议用完让它复述一遍这个技能是干嘛的、什么时候用，没问题再让它干活。
